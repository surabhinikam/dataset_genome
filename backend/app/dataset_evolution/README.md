# Dataset Evolution Engine — Dataset Genome Phase 2

The `dataset_evolution` module implements an explainable **Evolution Planning Engine**. It analyzes `DatasetAnalysisReport` objects generated by Dataset Intelligence, detects quality gaps, domain deficiencies, and reasoning flaws, and generates a structured, prioritized `EvolutionPlan`.

---

## Directory Structure

```text
dataset_evolution/
│
├── __init__.py      # Module exports (EvolutionPlanner, EvolutionPlan, Exporters)
├── planner.py      # Core EvolutionPlanner class for issue detection and plan assembly
├── recommender.py  # Prioritized recommendation generation engine
├── models.py       # Pydantic v2 schemas for EvolutionPlan, Issues, and Recommendations
├── report.py       # JSON and Markdown plan export utilities
└── README.md       # Architecture & usage documentation
```

---

## Evolution Planning Architecture

```text
DatasetAnalysisReport
         │
         ▼
  EvolutionPlanner (Issue Identification & Severity Assignment)
         │
         ▼
 EvolutionRecommender (Actionable Recommendation Generation)
         │
         ▼
  EvolutionPlan (Prioritized Plan & Health Score Trajectory)
```

---

## Data Models

### `EvolutionIssue`
Identifies specific dataset deficiencies (e.g. `domain_diversity < 0.50`, `hard_difficulty_ratio < 0.30`).
- **Severity Levels**: `CRITICAL`, `HIGH`, `MEDIUM`, `LOW`.

### `EvolutionRecommendation`
Actionable recommendation with estimated sample volume and health gain projection.
- **Action Categories**:
  - `Generate laboratory experiments` (Physics, Chemistry)
  - `Generate clinical trials` (Medicine)
  - `Generate simulation studies` (Climate Science, Biology)
  - `Generate harder reasoning samples` (Difficulty balancing)
  - `Generate missing scientific domains` (Domain expansion)
  - `Increase hypothesis diversity`
  - `Increase failure case diversity`

### `EvolutionPlan`
Structured output containing baseline health score, projected health score, total recommended sample count, issues, and recommendations.

## Usage Example

```python
from app.dataset_intelligence import DatasetAnalyzer
from app.dataset_evolution import EvolutionPlanner, export_plan_markdown

# 1. Run Dataset Intelligence
analyzer = DatasetAnalyzer()
report = analyzer.analyze_file("datasets/raw/scientific_reasoning_v1.jsonl")

# 2. Generate Evolution Plan
planner = EvolutionPlanner()
plan = planner.create_plan(report)

print("Baseline Health Score:", plan.baseline_health_score)
print("Projected Health Score:", plan.projected_health_score)
print("Total Recommended Samples:", plan.total_recommended_samples)

# 3. Export Markdown Plan
export_plan_markdown(plan, output_path="datasets/metadata/evolution_plan.md")
```
