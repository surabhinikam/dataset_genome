# Dataset Intelligence Engine — Dataset Genome Scientific Reasoning Benchmark

The `dataset_intelligence` module analyzes JSONL scientific reasoning datasets generated by Dataset Generator and computes comprehensive quality analysis reports, 8-stage reasoning coverage metrics, diversity scores, schema completeness indicators, and normalized 0–100 health scores.

---

## Directory Structure

```text
dataset_intelligence/
│
├── __init__.py      # Module exports (DatasetAnalyzer, DatasetAnalysisReport, Exporters)
├── analyzer.py      # Core DatasetAnalyzer class for processing JSONL files & in-memory batches
├── metrics.py       # Calculators for general statistics, reasoning coverage, diversity, and quality
├── scoring.py       # Normalized 0-100 dataset health score calculator
├── models.py        # Pydantic v2 schemas for reports and metrics
├── report.py       # JSON and Markdown report export utilities
└── README.md        # Documentation and architecture guide
```

## Metric Breakdown & Health Scores

### 1. General Statistics
- **`total_samples`**: Total count of analyzed scientific reasoning records.
- **`domain_distribution`**: Breakdown of sample counts across scientific domains (e.g. Agriculture, Medicine).
- **`difficulty_distribution`**: Sample counts by difficulty level (`easy`, `medium`, `hard`).
- **`average_prompt_length`**: Average prompt character count.
- **`average_context_length`**: Average context character count.

### 2. Reasoning Coverage Metrics (0.0 to 1.0)
Calculates coverage ratios for all 8 scientific reasoning steps:
- Observation coverage
- Problem coverage
- Research gap coverage
- Primary hypothesis coverage
- Alternative hypothesis coverage
- Experiment design coverage
- Failure case coverage
- Scientific conclusion coverage

### 3. Diversity & Quality Ratios
- **Diversity**: Domain diversity, experiment design diversity, evaluation metric vocabulary diversity, failure case diversity.
- **Quality**: Dataset completeness ratio, schema consistency percentage, missing field aggregate count, duplicate sample detection.

### 4. Normalized Health Scores (0–100 Scale)
- **Knowledge Coverage Score**: Domain breadth & 8-stage coverage combination.
- **Reasoning Quality Score**: Core hypothesis, gap, and experiment completeness.
- **Experiment Diversity Score**: Uniqueness across experimental setups, metrics, and failure cases.
- **Scientific Completeness Score**: Schema adherence and non-empty field percentage.
- **Overall Dataset Health Score**: Weighted composite dataset quality score.

## Usage Examples

### 1. Analyzing a JSONL Dataset File

```python
from app.dataset_intelligence import DatasetAnalyzer, export_report_markdown

analyzer = DatasetAnalyzer()

# Analyze datasets/raw/scientific_reasoning_v1.jsonl
report = analyzer.analyze_file("datasets/raw/scientific_reasoning_v1.jsonl")

print("Overall Health Score:", report.health_scores.overall_dataset_health_score)
print("Knowledge Coverage:", report.health_scores.knowledge_coverage_score)

# Generate Markdown Summary Report
md_str = export_report_markdown(report, output_path="datasets/metadata/intelligence_report.md")
```

### 2. In-Memory Analysis

```python
from app.dataset_generator import DatasetGenerator
from app.dataset_intelligence import DatasetAnalyzer

generator = DatasetGenerator()
records = generator.generate("Agriculture", 20)

analyzer = DatasetAnalyzer()
report = analyzer.analyze_records(records)
```
