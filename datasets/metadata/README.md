# Dataset Genome Pipeline Datasets

This directory manages datasets used across the Dataset Genome scientific reasoning pipeline, supporting data ingestion, gap analysis, sample evolution, and model fine-tuning splits.

## Directory Structure & Purpose

- **`raw/`**: Original generated scientific reasoning dataset.
- **`evolved/`**: Dataset after Dataset Genome has identified knowledge gaps and evolved the samples.
- **`final/`**: Train/Validation/Test splits used by Adaptive Data and AutoScientist.
- **`metadata/`**: Dataset statistics, schema documentation, and version information.
